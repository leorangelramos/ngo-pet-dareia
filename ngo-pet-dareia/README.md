🐾 Coletivo Pet D'Areia - Website

Portal oficial da ONG Coletivo Pet D'Areia, dedicado à proteção, resgate e adoção de animais.

URL do Projeto: https://petdareia.netlify.app/

📋 Sobre o Projeto

Este website foi desenvolvido para servir como um hub central para a ONG. Ele permite que visitantes conheçam a missão, vejam os animais disponíveis para adoção em carrosséis interativos e façam doações de forma fácil. O design é acolhedor e focado na experiência do usuário, com um fundo de vídeo imersivo.

✨ Funcionalidades Principais

Carrossel Multimídia: Sistema personalizado em JavaScript (js-carousel) que suporta imagens, vídeos e áudios no mesmo slide, permitindo uma apresentação rica de cada animal.

Vídeo de Fundo (Hero Video): Um vídeo em loop que cria uma atmosfera emocional imediata ao entrar no site.

Navegação Suave: Links de âncora (#) que deslizam suavemente até a seção correspondente.

SEO & Social: Otimização completa com Meta Tags, Open Graph (para compartilhamento no WhatsApp/Facebook) e JSON-LD (Schema.org para ONGs).

Responsividade: Layout adaptável que funciona bem em celulares, tablets e desktops.

🛠️ Tecnologias Utilizadas

HTML5 Semântico: Estrutura acessível e organizada.

CSS3: Variáveis CSS (:root) para fácil manutenção de cores, Flexbox para layout e transições suaves.

JavaScript (Vanilla): Lógica do carrossel leve e sem dependências externas.

📂 Estrutura de Arquivos

Para que o site funcione corretamente, certifique-se de que os arquivos de mídia estejam na pasta raiz:

/
├── index.html # Código fonte principal
├── sitemap.xml # Mapa do site para o Google
├── 1.png, 3.png # Logos e Favicons
├── petsdareia1.mp4 # Vídeo de fundo principal
├── pixqrcode.png # QR Code para doações
├── Max - Gato Siames.mp4 # Vídeos dos animais
├── max siames 01.jpg # Fotos dos animais
└── ... (outros arquivos de mídia)

🚀 Como Rodar Localmente
Baixe todos os arquivos para uma pasta no seu computador.

Certifique-se de que os vídeos e imagens citados no código existam na pasta.

Abra o arquivo index.html em qualquer navegador moderno (Chrome, Firefox, Edge).
